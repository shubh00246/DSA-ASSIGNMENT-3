# Campus Navigation and Utility Planner
### Data Structures Assignment – Trees & Graphs (Assignment 03)

This project implements a complete **Campus Navigation and Utility Planning System** using  
**Binary Search Trees, AVL Trees, Graphs, BFS, DFS, Dijkstra, Kruskal, and Expression Trees**.

It is designed according to the assignment requirements for  
**B.Tech CSE / DS – Semester 3 – ENCS205 (Data Structures)**.

---

## 📌 Features Implemented

### ✔ **Part 1 — Tree Implementation**
#### **1. Binary Search Tree (BST)**
- Insert Building Records  
- Search Buildings  
- Inorder, Preorder, Postorder Traversal  
- Stores: `BuildingID`, `BuildingName`, `LocationDetails`

#### ✔ **2. AVL Tree**
- Self-balancing tree  
- Demonstrates LL, RR, LR, RL rotations  
- Height comparison with BST  
- Faster search & insertion

---

## ✔ **Part 2 — Graph Implementation**

### **1. Graph Representations**
- **Adjacency Matrix**
- **Adjacency List**

### **2. Graph Traversals**
- Breadth-First Search (BFS)
- Depth-First Search (DFS)

### **3. Algorithms**
#### **Dijkstra’s Algorithm**
- Shortest navigation path between campus buildings

#### **Kruskal’s Algorithm (MST)**
- Cost-optimal utility layout (cables, pipelines)

---

## ✔ **Part 3 — Expression Tree**
Used for **energy bill calculations** and expression evaluation.  
- Builds tree from **postfix expression**
- Supports evaluation and inorder display
